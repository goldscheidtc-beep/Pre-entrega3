--- Pre-Entrega 3:Script SQL para esquema normalizado y datos iniciales ---

Se realiza un script SQL para crear y cargar la base de datos Ventas_Tech_DB

En la Sección 1 utilizando DROP se eliminan las tablas si es que ya existen.   
En la Sección 2 utilizando CREATE TABLE se crean las tablas indicando sus PK y FK.
En la Sección 3 utilizando INSERT INTO se cargan los 25 registros iniciales.
En la Sección 4 utilizando SELECT * se realiza la VALIDACIÓN de las tablas y como resultado las consultas devuelven 4, 5, 6 y 10 filas.

El script fue probado en SQL Server 22 con SSMS. corriendo completo y sin errores, siendo repetible, es decir que se ejecuta varias veces.
